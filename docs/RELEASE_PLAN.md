# Release Plan

## Stage 1: Foundation

- Validate the Rust installation.
- Establish the repository.
- Select the GUI framework through a prototype.
- Establish formatting, compilation, and CI checks.

## Stage 2: Application shell

- Build the primary window.
- Implement navigation.
- Implement accessible defaults.
- Implement the first-run setup wizard.
- Implement editable settings.

## Stage 3: Learning foundations

- Define lesson and exercise formats.
- Implement learning-path navigation.
- Add the first reviewed programming content.
- Add progress tracking.

## Stage 4: Review and personalization

- Add rule-based recommendations.
- Add review history.
- Add non-monetary XP.
- Add achievements and optional reminders.

## Stage 5: Reliability

- Implement persistent storage.
- Add migrations and recovery behavior.
- Validate content packs.
- Test accessibility.
- Run automated tests.

## Stage 6: Cross-platform release preparation

- Validate Windows.
- Validate Linux.
- Validate macOS.
- Prepare platform-appropriate packages.
- Document installation and uninstallation.
- Review privacy and security.
- Test upgrade and data preservation behavior.

## Release policy

Do not advertise unfinished features as complete.

Do not claim that a platform is supported until its essential workflows have been tested.
