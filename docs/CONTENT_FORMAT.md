# Learning Content Format

## Purpose

This document outlines the intended organization of learning content. The final machine-readable schema will be defined before content-pack installation is implemented.

## Planned concepts

A lesson should eventually include:

- Stable identifier.
- Title.
- Summary.
- Language or subject.
- Learning objectives.
- Prerequisites.
- Explanation sections.
- Examples.
- Exercises.
- Recap.
- Estimated duration.
- Content version.
- Attribution and licensing information where applicable.

## Validation

Content should be validated before use.

Validation should check required fields, supported versions, duplicate identifiers, invalid references, and resource limits.

## Future formats

A versioned JSON or another suitable structured format may be used after a prototype and schema review.

Do not assume this planning document is itself an implemented schema.
