# Accessibility Requirements

Accessibility is a core product requirement.

## Planned controls

- Adjustable text size.
- Readable contrast options.
- Keyboard-accessible navigation.
- Visible keyboard focus.
- Clear labels and understandable wording.
- Adjustable explanation depth.
- Adjustable reading density.
- Flexible lesson lengths.
- Optional reminders.
- Useful error messages.
- Predictable navigation and consistent interaction patterns.

## Design principles

Do not make optional setup questions mandatory without a compelling reason.

Avoid presenting too many unfamiliar controls at once.

Allow users to revisit setup choices through Settings.

Do not require users to disclose a diagnosis to access useful preferences.

## Validation

Test keyboard-only navigation and relevant accessibility tooling when the GUI framework has been selected.

Accessibility must be tested in the actual application, not inferred from the framework's marketing claims.
